# Simmetry

Simmetry is a simple web-based floor plan builder designed to make early home planning more approachable for homeowners and DIY users.

## Project Goal

The goal of Simmetry is to provide a basic visual workspace where users can create and experiment with simple floor plan layouts without the complexity of professional CAD software.

## Current Features

- Floor plan grid workspace
- Room and element tool panel
- Basic room properties
- New plan functionality
- Responsive application layout

## Development Status

Simmetry is currently in early development. The first development sprint focused on establishing the application's HTML structure, visual design, and basic JavaScript functionality.

Future sprints will focus on making the floor plan workspace more interactive.

## Technologies

- HTML5
- CSS3
- JavaScript
- GitHub Pages
